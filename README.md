# Portafolio Profesional — Alejandro Mendoza

¡Bienvenido al repositorio de mi portafolio web personal! Este espacio está diseñado para presentar mi perfil profesional, trayectoria académica, habilidades técnicas y los proyectos más destacados en los que he trabajado como **Ingeniero en Sistemas Computacionales** y **Desarrollador Web**.

## 🚀 Tecnologías del Proyecto

Este portafolio ha sido construido utilizando tecnologías modernas para garantizar un alto rendimiento, optimización SEO y una experiencia de usuario sobresaliente:

* **Framework:** [Next.js](https://nextjs.org/) (App Router & React)

* **Iconos:** [Lucide React](https://lucide.dev/)
* **Fuentes:** Optimización automática a través de `next/font`

## 📁 Proyectos Destacados

En el portafolio se detallan los siguientes desarrollos clave:

### 1. Sistema Integral de Información
* **Descripción:** Plataforma centralizada para la gestión unificada de procesos académicos, administrativos y de control escolar. Permite la administración de expedientes, el seguimiento de trayectorias estudiantiles y la automatización de trámites institucionales bajo una arquitectura segura y escalable.
* **Stack:** React, Laravel, PostgreSQL, Tailwind CSS.

### 2. ERP de Gestión Deportiva y Administrativa (Escuela de Fútbol Celaya FC)
* **Descripción:** Software integral diseñado para optimizar los procesos operativos, deportivos y financieros de la escuela de fútbol oficial de **Celaya FC**. Automatiza el registro de jugadores y tutores, seguimiento de estadísticas en torneos, control de pagos y mensualidades mediante Stripe, y el boletaje para partidos.
* **Stack:** Vue, Laravel, MariaDB, PrimeVue, Stripe API.

## 🔧 Configuración y Ejecución Local

Para correr este portafolio de manera local, sigue los siguientes pasos:

### 1. Clonar el repositorio
```bash
git clone https://github.com/AlejandroMendozaP/portafolio.git
cd portafolio
```

### 2. Instalar dependencias
```bash
npm install
```

### 3. Iniciar el servidor de desarrollo
```bash
npm run dev
```
Abre [http://localhost:3000](http://localhost:3000) en tu navegador para visualizar la aplicación.

### 4. Construcción para producción
```bash
npm run build
npm run start
```
